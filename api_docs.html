📚 API Endpoint Reference

POST
/api/coach/chat

Interactive conversational AI coach endpoint. Takes a user message, inspects today's logged activities, streaks, and fitness goals, and generates personalized coaching guidance, workouts, and nutrition tips.

Auth: Bearer Token or Session Cookie • Payload: {"message": "string"}
GET
/api/coach/tips

Returns dynamic, algorithmic daily wellness tips (custom workout recommendation, nutrition guide, recovery instructions, and streak alert) tailored to the student's daily activity status.

Auth: Bearer Token or Session Cookie
POST
/api/notifications/send-daily-digest

Dispatches a responsive HTML email containing the student's daily activity scorecard, points, active streak, and personalized coach tips straight to their mailbox. In demo environments without SMTP, records safe simulation logs and provides full HTML preview.

Auth: Bearer Token or Session Cookie • Payload (Optional): {"email": "student@campus.edu"}
GET
/api/notifications/history

Retrieves audit logs of all emails and notifications dispatched to this user.

POST
/api/activities

Logs a new physical activity for the student. Automatically calculates points, increments streaks, evaluates badge milestones, and returns instant AI coach feedback.

Auth: Bearer Token or Session • Payload: {"activity": "Running", "minutes": 30}
GET
/api/activities/daily-summary

Aggregates today's minutes, points, list of activities, and progress toward the 240-minute weekly campus target.

POST
/api/auth/register

Registers a student account and issues an API Bearer token for mobile apps.

Payload: {"name": "string", "email": "string", "password": "string", "goal": "string"}
POST
/api/auth/login

Validates student/admin credentials and issues a fresh 30-day Bearer token.

Payload: {"email": "string", "password": "string"}
GET
/api/dashboard

High-performance consolidated snapshot for mobile and frontend apps: user stats, streak, badges, 7-day chart data, and daily coach tips.
